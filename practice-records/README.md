# Optional practice records

Save a short record only when the learner requests or accepts it. Ordinary practice has no automatic archive block. Use [_template.md](_template.md), omitting optional sections that were not observed. Keep original attempts distinct from revisions and model examples. Do not invent timing, audio observations, or a profile.

Within this project's local setup, save requested records to `exports/practice-records/`. Other installations may use a learner-selected folder. This template is not input to either existing GitHub archiver. Existing polished-response and Buffer schemas and destinations are unchanged.

Record provenance and whether the material was familiar, generated, adapted, or reused. Distinguish first play, replay, transcript assistance, and script-only work. Use accessible past records to reduce repetition and choose a next target, without claiming to remember unseen history. Compare fresh-material accuracy within the actual time limit, evidence selection, and cue retrieval; do not convert practice accuracy into official section scores.
