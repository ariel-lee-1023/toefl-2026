# 09-invalid-challenge

I reassessed your proposed answer, “Do you know whether is the library open?” It still has a grammatical error.

Its tile use and fixed frame are mechanically valid. The problem is the embedded clause: after `whether`, use **the library is open**, with the subject before its verb. The question mark applies to the whole question; it does not require inversion in every clause.

Correct: **Do you know whether the library is open?**

Slots: `whether / the library / is / open`. Unused: `are`.

The outer question already has inversion in `Do + you + know`. Compare the separate direct question “Is the library open?” with the embedded clause `whether the library is open`. The key remains justified by that distinction, not merely because it was supplied first.
