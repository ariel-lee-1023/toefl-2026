# 01-direct-embedded

**Do you know whether the library is open?**

Slots: `whether / the library / is / open`. Unused: `are`.

The outer question is `Do + you + know`. After `whether`, the embedded clause uses subject–verb order: `the library + is`, not `is + the library`. The singular subject `the library` takes `is`. The completed question asks whether a possible study location is open, so it fits the context.
