# 02-interactive

Here is one original targeted exercise using a textual tile interface.

Context: You want to catch the campus shuttle and need its departure time.

Fixed frame: `Can you tell me [s1] [s2] [s3]?`

Shuffled tiles:

| ID | Tile |
|---|---|
| t1 | leaves |
| t2 | when |
| t3 | the next shuttle |
| t4 | leave |

Put one intact tile in each slot and identify the unused tile. You can reply with tile IDs or the complete question.
