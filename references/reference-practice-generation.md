# Original practice generation

Status: original item-design workflow, created 2026-09-14. Use [ETS specifications](reference-ets-reading-listening-specs.md) for task mechanics and the relevant course/coaching reference for the learning target. Generated items are original practice, never official ETS items or a calibrated adaptive test.

## Three modes

| Mode | Preserve | Vary |
|---|---|---|
| Existing material, new questions | Supplied text or recording and its factual content | Question focus, evidence links, paraphrases, distractors, relation matching |
| New original material | Coherent, self-contained support for every answer | Topic, setting, speakers, structure, vocabulary, and relationships |
| Focused micro-exercises | One clear target such as conditions, intent, or reference links | Evidence selection, paraphrase repair, example-to-claim matches, minimal meaning changes |

Choose mode by the request. For reuse, do not silently rewrite the source to support a desired key. If five independent questions cannot be supported by a tiny source, explain the constraint and offer fewer questions or explicitly broader skill exercises. If an adaptation is requested, label the changed version and preserve the original separately.

Accept task type, target skill, approximate difficulty, length, quantity, and interactive/batch preferences. Default to one original short task at a moderate design difficulty, interactive delivery, and one learning target. For a named official task, follow its format rather than substituting a generic micro-exercise. Use accessible prior practice records to avoid repetition; otherwise vary topics and relationships without claiming knowledge of prior work. Do not repeatedly make the correct answer the cautious, longest option.

## Task constraints and design defaults

| Task | Generation rule |
|---|---|
| Complete the Words | Follow the verified intact-first-sentence, alternating-word, ten-gap pattern in a 70–100-word academic text. Each underscore represents exactly one missing letter. For an odd-length word, the local rendering convention retains the first floor(length/2) letters and deletes the rest, consistent with the reviewed sample; this is not a claim about all tokenization edge cases. Avoid contractions, punctuation-heavy terms, and one-letter target words by revising the intact source before masking. |
| Read in Daily Life | Create a plausible practical text. Use two or three questions for format-aligned sets, covering purpose and independently supported details/implications. Five requested questions on one short text should be labelled an expanded learning set. |
| Read an Academic Passage | Aim around 200 words and five supported questions for a format-aligned set. Define needed subject terms in the text. Vary organization instead of always using definition plus examples. |
| Choose a Response | Audio utterance with four written replies. Exactly one should fit the intention and context best. A direct information reply and an equally appropriate indirect reply in the same set create ambiguity. |
| Conversation | Two intelligible speaker roles, a small practical situation, and a clear relation such as a revised plan. Local default: 60–100 words, two questions; this word range is a design choice, not an official universal limit. |
| Announcement | One speaker in an academic/campus setting, roughly 40–85 words using the ETS sample guidance. Local default: two questions, about purpose and a distinct detail or action. |
| Academic Talk | Self-contained concept or explanation with useful organization. Local default: 150–220 words and four questions, within the blueprint's extended-audio limit of 250 words; local defaults do not promise exact operational forms. |

Micro-exercises may depart from these sizes and response formats but must be labelled skill-building, not an exam simulation. Difficulty is an estimate controlled through syntax, referential distance, relationship complexity, information density, vocabulary support, and distractor closeness. Do not manufacture difficulty through obscure outside knowledge, ambiguity, distorted audio, or arbitrary speed. Keep pronunciation and rate adjustable for learning and disclose scaffolding.

## Build the key before delivery

Keep the key separate from learner-facing questions. For each item, retain:

- The supported answer and exact text/verified audio evidence.
- The interpretation needed, including qualifiers or relation direction.
- Why each distractor fails and whether an alternative is defensible.
- Material provenance, assistance conditions, and a difficulty estimate.

For word completion, retain full word, visible prefix, missing suffix, count, grammatical form, and contextual clue. Check plausible competitors with the same prefix and length. A dictionary search may help but cannot establish contextual uniqueness by itself. Revise ambiguous items before delivery, or accept justified alternatives in learning mode. Reconstruct the entire paragraph to check spelling, agreement, coherence, and unchanged content.

Before publishing each item, solve it from the source without relying on the intended key. Check competing valid answers, outside-knowledge dependence, distractor overlap, exaggerated attitude, answer-position patterns, word overlap, and option-length clues. For an EXCEPT item, three supported choices and one unsupported choice must be demonstrable. For inference, state the premises and ensure no invented assumption is doing the work. A model's review is a quality check, not psychometric validation.

## Deliver without spoiling the attempt

Interactive: provide one task and wait. Never append its answer key or sample learner answer in that turn. Batch: provide the requested quantity and deliver a requested key as a separate artifact; otherwise retain it for later feedback. Full answer/explanation requests are honored immediately.

Listening: discover host capabilities and load [Audio delivery](reference-audio-delivery.md). Render the original script, compare it and the key, and verify audio correspondence to the extent supported by playback/recognition. Reveal neither the transcript nor answer-specific cues before an independent attempt. A neutral file name and duration are sufficient. If only text can be delivered, state the script-only boundary and offer script-based comprehension or guided work with an accessible learner recording. A script does not complete playable listening generation.

If the learner challenges the key with evidence, reassess without defending the original automatically. Accept or repair a flawed item; keep it out of progress claims. For delivery examples and a reviewed set, see [worked interactions](../evals/reading-listening/worked-interactions.md) and [questions](../evals/reading-listening/examples/questions.md), whose key is separate.
